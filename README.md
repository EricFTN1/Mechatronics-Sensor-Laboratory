# Mechatronics Sensor Laboratory

A collection of laboratory projects exploring sensor technologies, motor control systems, signal conditioning, calibration techniques, and embedded system integration commonly used in mechatronics and automation applications.

This repository contains code, reports, wiring diagrams, engineering notes, and supporting documentation developed throughout a university-level Mechatronics course.

---

## Overview

Throughout this course, various sensors, actuators, and measurement systems were analyzed, integrated, and tested through a series of hands-on laboratory exercises.

Topics explored included:

- Strain Gauges
- Temperature Sensors
- Capacitive Sensors
- Optical Sensors
- Signal Conditioning
- Data Acquisition
- Motor Control
- Embedded Systems Integration
- Calibration Techniques
- Experimental Measurement Methods

Each laboratory exercise contains source code, reports, setup documentation, and engineering notes related to the experiment.

---

## Contributions
This laboratory project was completed collaboratively. All team members contributed to the design, testing, and analysis of the experiment.

Throughout the course, I was responsible for the hardware integration, testing, documentation, and software implementation associated with the laboratory exercises.

Key responsibilities included:

- Developing embedded software for sensor interfacing and data acquisition.
- Designing and documenting wiring layouts and pin assignments.
- Performing sensor calibration and validation procedures.
- Collecting and analyzing experimental data.
- Creating technical reports and engineering documentation.
- Troubleshooting hardware and software integration issues.
- Implementing and testing motor control systems.
